# ModRetro Chromatic Plugin for Codex 1.0.25

If the built-in browser is unavailable, locked or unreachable, Codex keeps the
preview URL and state and continues gameplay checks with the existing headless
PyBoy tools on the intended exact ROM. Shared MCP guidance, tool descriptions
and playtest skills now make that route explicit, including supported setup
when the emulator dependency is missing.

Available browser previews stay visible during authoring. Native gameplay
evidence remains separate from browser UI, annotations, recordings and physical
device acceptance. Existing access denials, uncertain actions, user play and
saves retain their protections.

This release changes guidance and version metadata only. It builds on public
1.0.23; the separate unpublished 1.0.24 browser-step candidate and recording
diagnostics are not included.
