# ModRetro Chromatic 1.0.20

## A steadier player layout

The player keeps its controls in place when switching between Emulation and
Live view. Colors and capture controls sit beside the console, and the game
title sits on the bezel. A single row of keyboard hints and the Install control
sit below the console. Short panes use a compact color grid to avoid overlap.

Device settings use consistent spacing and typography across tabs. Opening
settings now focuses its active tab after the dialog opens. The More menu no
longer competes with the annotation gesture, and error details remain readable
and easy to copy.

The UI was checked in Chrome at 320 × 320, 320 × 568 and 593 × 711, alongside
focused interaction tests. A final emulator recording saved and reopened.
Physical-device capture and the Codex annotation gesture were not exercised
in that review. Existing setup, device consent and recovery behavior remain
in place.
