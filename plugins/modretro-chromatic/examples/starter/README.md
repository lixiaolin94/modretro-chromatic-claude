# Original starter

An editable native project with one quiet workshop, an original player, and no
story events, actors or triggers. Use it as a starting point for your own game.

The room, character, fixed-width font and dialogue UI are original artwork.
See [sample provenance](../SAMPLE-PROVENANCE.json) and the
[editable pixel sources](../original-art/README.md) for exact sources and hashes.
The font covers printable ASCII; lowercase has a small-caps appearance and
other characters use a question-mark fallback.

Copy the project to a writable folder, set up the separately installed compiler,
then build and preview your copy. No prebuilt cartridge is included. Native
project-format metadata retains its upstream license notice in `LICENSE`.
